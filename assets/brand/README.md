# LevelArc Brand Assets

These files are the working LevelArc logo set. Keep the original generated filenames out of app code; use these stable names instead.

- `levelarc-emblem-rich-circuit.png` — rich atmospheric version for splash, store graphics, README, and high-impact brand surfaces.
- `levelarc-emblem-simple-dark.png` — simplified dark square version for app icon, favicon, and small square placements.
- `levelarc-emblem-detailed-transparent.png` — transparent detailed emblem for in-app overlays, adaptive icon foreground, and dark UI surfaces.
- `levelarc-emblem-detailed-white.png` — white-background reference version for docs or contrast checks.
- `levelarc-emblem-detailed.svg` — editable source for the detailed emblem.
- `levelarc-emblem-simple.svg` — editable source for the simplified icon/emblem.

Current app entry assets in `assets/` are derived from these files.
